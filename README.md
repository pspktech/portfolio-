# 🎨 Madhu Patel — Developer Portfolio

A modern, responsive developer portfolio built with pure HTML, CSS, and JavaScript.

🔗 **Live:** [madhuupatel.netlify.app](https://madhuupatel.netlify.app)

---

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Smooth scroll navigation
- Typewriter animation in hero
- Project showcase with live links
- Skills section with icons
- Contact via Telegram & Instagram

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, animations
- **JavaScript** — vanilla JS (nav toggle, scroll effects)
- **Fonts** — Inter, Space Grotesk, JetBrains Mono (Google Fonts)
- **Hosting** — Netlify
